## 📌 Executive Overview

This unified monorepo houses all 15 advanced security engineering packages developed across Weeks 4 to 6. ## 🚀 Quickstart & Monorepo Setup

### 1. Clone & Set Up Environment
```bash
git clone https://github.com/MdPeerSiddiqui/Sqrock-Internship-Phase-2.git
cd Sqrock-Internship-Phase-2
python -m venv .venv
source .venv/bin/activate  # On Windows: .\.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Execute Day 16 Security Header Analyzer
```bash
cd Day16_HTTP_Security_Headers
python header_analyzer.py
```

### 3. Run Automated Unit Tests
```bash
python -m unittest discover -s . -p "test_*.py" -v
```
